# My First Repo

A tiny Python project made during **Lab 2** to practise git and GitHub.

## How to run

```
python greetings.py      # or: python3 greetings.py (Mac)
```

## What's inside

- `greetings.py`: a few friendly functions (`greet`, `farewell`, `shout`, ...)
- `motto.txt`: our lab motto

## What I learned

- `git status` — checks the current state of the repository.
- `git add` — stages changes for a commit.
- `git commit` — saves staged changes to Git history.
- `git switch` — switches between branches.
- `git merge` — combines changes from different branches.
